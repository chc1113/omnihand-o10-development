## Raw 接口验证

单独调用 `get_tactile_sensor_data_raw(Finger.THUMB)` 时，SDK 报告 `GetTactileSensorDataRaw is not supported by USB communication`，返回对象的 `data=[]`；`get_all_tactile_sensor_data_raw()` 返回空列表。这是 USB 后端能力限制，不是空载导致的零数据。USB 项目应使用 `get_tactile_sensor_data()` 的降采样接口。

## 判断

1. 当前右手 USB 通信、降采样触觉查询和状态读取均正常。
2. 没有施加压力时各点为 0 是正确现象，不能据此判断传感器失效。
3. 右手触觉传感器的有效性已有“受压非零、释放回零”的历史证据，但当前仍只覆盖拇指；五指和掌心区域需要按统一流程补测。
4. 在任何运动测试前，应先完成逐区域触觉标定，再做极小幅、可人工断电的位置写入验证。

## 运行注意

本次读取过程中没有调用广播设备信息接口。该接口会额外尝试 CANFD/SocketCAN，在本机没有 CAN 设备时打印初始化失败日志；这不是 USB 触觉失败。正式程序应固定 USB 后端、串口稳定路径和设备 ID，避免广播探测。
