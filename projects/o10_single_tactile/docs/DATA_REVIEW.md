# 现有资料审阅与首版路线

审阅日期：2026-09-17

补充验证：2026-09-18 已在已供电右手上完成 15 秒 USB 只读空载采集，详见 [LIVE_VALIDATION_20260918.md](LIVE_VALIDATION_20260918.md)。

## 1. 资料定位

`/home/chc/O10` 原有三个目录：

| 目录 | 实际用途 | 与本项目的关系 |
|---|---|---|
| `o10_single_vision` | 单视觉重定向与实机控制 | 独立项目；可复用其右手关节映射、安全限幅思想 |
| `o10_usb_phase1` | USB 只读通讯、状态和触觉实测 | 本项目的主要实体手证据与基线数据 |
| `o10_usb_test_bundle` | USB 测试迁移包，含简单触觉监视器 | 可复用读取方式，但不具备抓取闭环 |

因此新建 `o10_single_tactile`，避免把触觉抓取逻辑混入通信验证或视觉项目。

## 2. 实体手数据结论

### 右手

- 设备为 O10，设备 ID 1，硬件版本 3.0.0，软件版本 1.2.7，10 个主动关节。
- 位置只读：50 Hz 连续 5 分钟，共 15000 周期，实际 49.99999 Hz；位置读取 P99 0.772 ms、最大 0.955 ms，无失败或空返回。
- 全状态加 7 个降采样触觉区：10 Hz 连续 5 分钟，共 3000 周期，实际 10 Hz；全周期 P99 11.787 ms、最大 13.089 ms，各调用无失败或空返回。
- 空载记录中触觉为零。拇指轻压记录共 300 个周期，300/300 均出现非零；单点峰值 150，16 点阵列每周期总和均值约 592。释放记录共 100 个周期，100/100 全部回零。
- 同一拇指实验中其余手指、掌心和手背保持为零，说明至少在该实验里区域隔离是清楚的。

### 左手

- 位置只读同样可在 50 Hz 连续运行 5 分钟，无失败。
- 降采样触觉在现有轻触探测中没有得到可信压力响应；手背出现过零星值 1，接近噪声。
- 在补充逐区域、已知载荷实验前，左手不进入触觉抓取开发范围。

## 3. 官方 SDK 能力与限制

- SDK 版本为 1.1.5，O10 为 10 主动 + 6 被动自由度。
- `get_tactile_sensor_data()` 返回降采样数据：每根手指 16 点，掌心和手背各 25 点；文档标称单位 1 g、最大 255 g、采样频率 10 Hz。
- USB CDC 已实测支持上述降采样接口，但 `get_tactile_sensor_data_raw()` 和 `get_all_tactile_sensor_data_raw()` 在 USB 下为空或明确报不支持。
- `set_all_joint_positions()` 可批量设置 10 个电机位置并返回实际位置，但现有本地记录没有验证写入稳定性。
- O10 默认位置控制；纯力矩控制不支持。位置+电流混合控制是否适用于当前 USB 固件和右手，需要单独的小幅测试，不能依据 API 存在就直接采用。

结论：USB 首版适合做低带宽事件闭环，不适合声称高分辨率触觉或精确力控。需要完整 Raw 阵列或更严格时序时，转向 CANFD。

## 4. 模型结论

模型包包含左右手 URDF、精细碰撞 URDF 和 MuJoCo MJCF。右手模型有 10 个执行器；其余关节存在耦合。普通 URDF 只表达线性 mimic，MJCF/SDK 才包含更真实的非线性耦合关系。

首版可用模型完成三件事：

1. 固定电机索引、主动关节和手指区域的映射。
2. 在真机前检查预抓取姿态、自碰撞和关节范围。
3. 为后续滑移/抓取稳定性实验提供接触几何，但不能用仿真触觉替代实机标定。

## 5. 建议的最小抓取闭环

首版采用有限状态机：

```text
IDLE -> BASELINE -> APPROACH -> CONTACT -> HOLD -> RELEASE
                       |           |        |
                       +-------- FAULT <----+
```

- `BASELINE`：空载采样 2-3 秒，对每个触觉点估计基线和噪声，而不是只计算区域均值。
- `APPROACH`：从已验证的预抓取姿态开始，以小步长闭合相关屈曲关节；控制频率先取 10-20 Hz。
- `CONTACT`：触觉以 10 Hz 读取。使用“区域总和 + 峰值 + 连续多帧”判定接触，避免单点噪声触发。
- `HOLD`：停止继续闭合，保持当前位置；若触觉快速下降且位置未变，记录为疑似滑移并小步补偿。
- `RELEASE`：按限速轨迹回到已验证的张开姿态。
- `FAULT`：通信失败、数据长度异常、电机错误、温度/电流超限或循环超时时立即停止继续闭合，优先回退或人工断电。

首版不应直接使用固定阈值 8 g 作为最终接触标准。现有数据只覆盖一次拇指轻压，无法代表不同传感区、物体材料、曲率和接触面积。

## 6. 开发前必须补齐的实验

1. 右手五指和掌心逐区域空载/轻压/释放测试，每个区域至少重复多次。
2. 记录每点基线、噪声分布、迟滞、饱和、相邻区域串扰和释放时间。
3. 在手指完全空旷、可立即断电的条件下，验证 10 轴批量位置写入的小幅、低速、限时动作。
4. 建立电机索引到手指动作的真机映射，并与模型和单视觉项目配置交叉核对。
5. 先用软质大物体完成“接触即停”，再测试保持和滑移补偿；每一步保留原始触觉、位置、电流、温度和错误状态。

只有完成以上实验，才能合理设定每指阈值、最大闭合步长、超时、回退量和稳定抓取判据。

## 7. 推荐执行顺序

### 阶段 A：触觉标定（只读）

1. 保持手部空载，采集 10 Hz、至少 30 秒基线；保存每点均值、标准差、最大值和异常帧。
2. 对拇指、食指、中指、无名指、小指、掌心分别做轻微、可重复、短时接触；每个区域做“接触—保持—释放”三段记录。
3. 每次只接触一个区域，确认非目标区域没有同步升高；重复至少 3 次。
4. 以 `baseline + 3σ` 和连续 2-3 帧作为初始接触判据，再根据数据调整，不把 `8 g` 固定阈值直接用于所有区域。

### 阶段 B：电机索引与小幅动作验证（受控写入）

1. 先核对 `o10_single_vision` 的右手电机映射、模型主动关节和 SDK 的 10 轴顺序。
2. 手指周围清空，准备立即断电；只允许 5%-10% 行程、5 Hz 起步、单指或单组关节动作。
3. 每次写入后读取位置、错误、温度和电流；出现异常、超时或位置不符立即停止。
4. 将预抓取姿态、张开姿态和每个动作步长写入配置，不在代码中散落魔数。

### 阶段 C：接触即停闭环

1. 从已验证的预抓取姿态开始，以 10 Hz 触觉读取和 10-20 Hz 位置小步逼近运行。
2. 每一步限制最大位置变化，并在连续接触帧达到阈值后停止继续闭合。
3. 首版只实现 `APPROACH -> CONTACT -> HOLD -> RELEASE`，不实现自动滑移补偿和力矩控制。
4. 记录触觉原始降采样数组、位置、角度、电流、温度、错误、状态机状态和时间戳。

### 阶段 D：抓取稳定性

1. 先使用软质、大尺寸、易释放物体，验证接触即停不会挤压或弹飞物体。
2. 再逐步测试不同材质和重量；每次只改变一个变量。
3. 将“接触成功、保持成功、滑移、误触发、超时、故障停止”分类统计。
4. 只有 USB 降采样闭环长期稳定后，才考虑 CANFD、Raw 触觉或更高带宽的研究方向。
