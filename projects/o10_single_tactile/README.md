# O10 单触觉项目

本项目面向智元 OmniHand 2025 O10 的触觉二次开发。第一阶段目标是使用右手的触觉反馈完成低速、可中止的抓取闭环，并建立可复现的数据记录与安全验证流程。

## 当前结论

- `o10_usb_phase1` 是实体手 USB 只读观测项目，提供本项目的基线数据，不是单触觉抓取项目。
- `o10_usb_test_bundle` 是迁移和测试交接包，其中的触觉脚本只能做接触监视，不是完整的单触觉抓取项目。
- 当前右手已验证 USB 降采样触觉有效；左手尚不能证明具有有效压力响应。因此首版只针对右手。
- USB 可读取 16 点/手指、25 点/掌心或手背的降采样触觉，标称 10 Hz、每点 0-255 g；USB 不支持官方 Raw 全分辨率接口。
- 现有记录只验证了只读链路和右手拇指受压/释放，没有验证位置写入、抓取动作和稳定持握。
- 2026-09-18 实时空载验证通过：150 个周期、10 Hz、7 个区域固定长度且全部为零，与历史空载数据一致。

详细证据和开发路线见 [docs/DATA_REVIEW.md](docs/DATA_REVIEW.md)；本次实时验证见 [docs/LIVE_VALIDATION_20260918.md](docs/LIVE_VALIDATION_20260918.md)。

## 目录

```text
o10_single_tactile/
├── config/      # 设备、阈值和抓取策略配置
├── data/        # 本项目整理后的离线数据
├── docs/        # 设计、实验和结论文档
├── models/      # 1769933923166393 模型包的独立副本
├── records/     # 本项目产生的原始实验记录
├── scripts/     # 校准、采集和实验入口
├── sdk/         # 用户提供的官方 SDK 独立解压副本
├── src/         # 触觉处理、状态机和硬件适配代码
└── tests/       # 离线与硬件测试
```

## 数据来源边界

- 官方 SDK：`sdk/agillink_omnihand_sdk-main`，版本 1.1.5。
- 模型：`models/omnihand_description-omnihandT2_1`，含左右手 URDF、精细碰撞 URDF 和 MuJoCo MJCF。
- 既有实测数据：`../o10_usb_phase1/records`，保持原地只读引用，不复制、不改写。
- 既有测试工具：`../o10_usb_test_bundle`，作为实现参考，不作为本项目运行依赖。

## 安全边界

在完成右手各触觉区域校准和小幅位置写入验证前，不执行自动闭合抓取。首版控制策略采用“位置小步逼近 + 触觉停止/回退”，不把降采样触觉值直接解释为精确法向力，也不把 USB 链路描述为实时总线。
