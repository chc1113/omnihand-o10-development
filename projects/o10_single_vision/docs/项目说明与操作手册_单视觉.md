# 单视觉灵巧手项目说明与操作手册

## 读者与目标

本文面向第一次接触本项目的研究生。读完后应能解释算法、运行仿真、理解输出，并知道哪些结果仍需研究验证。

## 一句话原理

摄像头看到人手后，MediaPipe 给出 21 个三维相对关键点；程序用关键点之间的角度、距离和方向计算手指特征，再把 0 到 1 的特征换算成 O10 关节角，最后在 MuJoCo 虚拟模型中显示。

## 算法组成

### 摄像头与 MediaPipe

默认打开 `/dev/video0`，分辨率 640×480，画面水平翻转后送入 MediaPipe Hands。MediaPipe Hands 是预训练神经网络，不是本项目训练的模型。它先检测手，再跟踪手，输出每只手 21 个 landmark。新版按标签和置信度选择右手，并优先采用世界关键点；世界关键点比图像归一化坐标更适合三维角度，但仍不是经过相机标定的精确毫米测量。

### 几何特征

程序先以小指 MCP 指向食指 MCP 建立掌横轴，再把腕到中指 MCP 的方向正交化为掌纵轴，两者叉乘得到掌法向。四指弯曲同时使用 MCP-PIP-DIP 和 PIP-DIP-TIP 两个夹角。食指、无名指、小指侧移取 MCP 到 PIP 的近节指骨方向，因此能反映真正的侧向张开；中指没有独立侧移主动关节。拇指 roll/abad 取拇指基部指骨在掌坐标中的方向，弯曲则由两个局部夹角和掌根距离计算，减少相互耦合。

### 重定向

“重定向”就是把人手坐标换成机器人关节命令。特征先归一化到 0～1，再按 O10 每个关节的不对称最小值和最大值换算为弧度。当前 10 个主动关节顺序为：拇指 roll、拇指 abad、拇指 mcp、食指 abad、食指 pip、中指 pip、无名指 abad、无名指 pip、小指 abad、小指 pip。6 个被动关节由 `model_constraints.py` 的近似公式产生。21 个视觉点不等于 21 个执行器。

### 平滑与仿真

目标关节角使用指数移动平均，`smooth_alpha=0.25`，减少抖动但会增加响应延迟。MuJoCo 部分按关节名字写入 qpos，再调用 `mj_forward` 更新几何姿态。它是运动学显示，不是动力学仿真：没有执行器 ctrl、`mj_step`、碰撞力控制或反馈。

## 操作流程

在终端执行：

```bash
cd /home/chc/O10/o10_single_vision
bash scripts/run_sim.sh
```

出现两个窗口后，摄像头窗口显示关键点和诊断值，MuJoCo 窗口显示虚拟手。按 `q` 或 `Esc` 退出。只看静态模型可执行：

```bash
bash scripts/run_sim.sh --no-camera
```

若有多个摄像头，可用 `--camera 1` 临时覆盖编号。无手时程序保持上一姿态，这是设计行为，不代表检测仍然成功。

## 标定和测试

运行 `.venv/bin/python scripts/calibrate_all.py`，按屏幕依次完成七个姿态。程序把原始 21 点、置信度和特征写入 `data/calibration_samples.jsonl`，再由求解器生成 `config/calibration_right.json`；仿真和真机都会自动加载。`scripts/test_retargeting.py` 已检查几何旋转缩放不变性、侧移、末端弯曲、范围和限速，但合成测试仍不能替代真人验收。

## 真机操作

先确保独立 24 V 电源、USB 数据线和机械运动空间安全。执行 `bash scripts/run_real.sh --probe-only`，只读确认 10 个主动关节和错误状态。个人标定和仿真验收通过后，执行 `bash scripts/run_real.sh --arm REAL_HAND`。右手连续有效 12 帧后窗口显示 READY，再按 `a` 开始；空格暂停，`q` 或 Esc 停止。首轮只允许初始实测位置附近 8% 全行程，10 Hz 写入，丢手 0.25 秒即停止继续写入。

## 常见名词

| 名词 | 通俗解释 |
| --- | --- |
| landmark | 手上的一个关键点，例如指尖或关节 |
| MediaPipe | Google 提供的预训练手部关键点检测方案 |
| feature | 从关键点计算出的数字，如弯曲程度 |
| curl | 手指弯曲程度，0 近似伸直，1 近似弯曲 |
| abduction 或 abad | 手指相对手掌向侧面张开 |
| roll | 拇指绕自身/掌面方向的转动量 |
| retargeting | 把人手动作转换成机器人关节动作 |
| qpos | MuJoCo 中关节的位置变量 |
| 主动关节 | 直接由命令设定的关节 |
| 被动关节 | 由约束公式跟随主动关节变化的关节 |
| EMA 平滑 | 新值和旧值按比例混合，降低抖动 |
| 运动学 | 只描述姿态和几何，不计算力和加速度 |
| 动力学 | 进一步计算力、质量、加速度和执行器响应 |
